# BreadLab Project Overview

BreadLab is a Laravel 10 bakery business management system.

The project started as an online bakery store, but is now being developed into a full outlet operation system.

## Core Scope

- Online product catalog
- Customer checkout
- Manual payment
- Pickup, local delivery, and shipping
- Admin order management
- Cashier/POS
- Cashier shift and cash flow
- Multi-outlet management
- Division-based stock opname
- Inventory control
- Supplier and purchasing workflow
- Waste tracking
- Sales target
- Operational expenses
- Gross profit and net profit reporting
- Manager monitoring dashboard

## Main User Roles

- super_admin
- admin
- manager
- staff_outlet
- cashier
- customer
