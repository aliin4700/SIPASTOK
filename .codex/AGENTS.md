# Project: Website Penjualan Toko Roti

Stack:
- Laravel 10
- Bootstrap
- Supabase database
- Google OAuth / Clerk
- Midtrans atau payment gateway opsional

Rules:
- Jangan hapus file penting tanpa izin.
- Gunakan migration Laravel untuk database.
- Pisahkan role user dan admin.
- Buat fitur pelanggan: register, login, katalog, cart, checkout, riwayat pesanan.
- Buat fitur admin: dashboard, CRUD produk, kategori, pesanan, laporan.
- Jalankan test atau minimal php artisan route:list setelah perubahan.
