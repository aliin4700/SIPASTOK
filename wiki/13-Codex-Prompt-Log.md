## Staff outlet melakukan:
- Opening operation
- Take bahan
- Production / WIP
- Waste record
- Closing stock opname
- Submit daily operation

## Rules
Closing operation wajib memiliki minimal satu stock opname:
- submitted, atau
- reviewed

## Admin
Admin dapat melihat detail daily operation dan approve status-only.

## Manager
Manager hanya read-only.
