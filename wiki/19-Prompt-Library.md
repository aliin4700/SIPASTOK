# Prompt Library

## Prompt update wiki
Update LLM Wiki berdasarkan perubahan terakhir.
Jangan ubah source code.
Hanya update file Markdown di folder /wiki.

## Prompt debugging
Baca wiki/00-Project-Overview.md dan wiki/18-Coding-Rules.md.
Analisis bug berikut tanpa langsung mengubah file.
Berikan penyebab, file terkait, dan rencana fix.

## Prompt implement fitur
Baca wiki terkait modul.
Kerjakan fitur secara incremental.
Jangan ubah modul lain.
Setelah selesai update wiki.
